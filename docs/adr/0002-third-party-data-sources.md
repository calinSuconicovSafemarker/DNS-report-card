# Third-party data sources chosen for browser access

Every source must allow cross-origin requests from a static site (see ADR 0001), checked live on 2026-11-13. DNS uses Cloudflare's DoH JSON API, with Google's JSON API as fallback; Google requests must stay "simple" GETs with no custom headers, because its CORS preflight returns no CORS headers. Certificates come from **Cert Spotter** (keyless, fast), with **crt.sh** as a slow fallback. crt.sh alone took 25 s or more and often returned 502s without CORS headers. HSTS preload status comes from **Chromium's preload list** fetched via jsDelivr, not the hstspreload.org API. That API allows only `localhost` and a few allowlisted origins, so it appears to work in local dev and breaks once deployed. The consequence is that the HSTS check can't report "pending" or "rejected", only whether a name is in the list.
